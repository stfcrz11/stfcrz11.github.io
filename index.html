OBE Curriculum Management System

Oct 2026 to present Project Manager and Documentation. Client project for the University of La Salette.

An Outcome-Based Education curriculum system for the university, with 6 user roles and a 7-step approval workflow from Program Head to Dean. It covers CHED CMO and SDG alignment, drag-and-drop planning and attainment tracking.

  • A local AI assistant drafts learning outcomes, suggests mappings and reads CHED memorandum orders. A person reviews every suggestion and each one is logged, following the university's AI policy.
  • About 90 API endpoints with 69 automated tests, Docker and HTTPS deployment, nightly backups and a one-click Windows setup.

Built with Flutter, FastAPI, PostgreSQL, Ollama, Docker, nginx

Sili-Tubig Clash

Sep 2026 Developer Support. Team of five, 2nd Runner Up at CODE & CONQUER Cagayan Valley.

A digital version of the Filipino street game Sili-sili, Maanghang, Tubig-tubig, Malamig. It has cheat-resistant LAN multiplayer: the host checks every action, players join with a 4-digit lobby code, and a dropped player can rejoin a match within 45 seconds.
